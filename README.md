# StageSpeak

Афиша тренингов по ораторскому мастерству на PHP + PostgreSQL.

## Быстрый запуск

1. Создайте базу PostgreSQL и выполните `schema.sql`.
2. Скопируйте `config.example.php` в `config.php` и укажите доступы.
3. Запустите: `php -S localhost:8000`.
4. Откройте `/admin.php` и войдите данными из `config.php`.

По умолчанию логин администратора `admin`, пароль `change-me-now` — обязательно смените их.
